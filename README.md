Main heading in high-impact bold text: 'O fim da incerteza no checkout digital'. Subheading: 'Acople linhas de receita líquida via Embedded Insurance diretamente na sua plataforma, com impacto zero em performance técnica'. Below the text, add two side-by-side buttons: a prominent neon-green button ('Solicitar Piloto de 30 Dias') and an outlined button ('Ver Documentação API').The Problem Section: Titled 'O Fantasma do Carrinho Abandonado'. Explain in a clean visual layout that buyers of high-ticket digital products abandon checkouts due to financial uncertainty (fear of missing events/mentorias due to health or logistics emergencies).The Solution Section (The Feature): Titled 'FlexInsur Guarantee'. Present a clean interactive mockup or graphical card simulating an e-commerce checkout box that features a checked checkbox '[X]' with the editable text 'Adicionar Garantia por R$ 29,90' and a locked icon indicating '🔒 Reembolso integral automatizado em caso de imprevistos médicos ou logísticos'.Win-Win-Win Ecosystem Section: Split into 3 columns with modern tech icons:Column A: 'Para Produtores' -> Destrava vendas retidas pelo medo do cliente e zera disputas de reembolso.Column B: 'Para Clientes' -> Proteção absoluta do capital investido contra imprevistos de saúde e transporte.Column C: 'Para Plataformas' -> Nova linha de receita pura via Revenue Share automatizado, sem custo operacional ou de suporte.Tech & Trust Section: Highlight that the API is asynchronous, lightweight, features automated AI document validation (OCR), and the financial risk is 100% backed by tier-1 SUSEP-regulated digital insurance companies in the backstage.Footer: Minimalist links, copyright text '© 2026 FlexInsur. Todos os direitos reservados. Disrupção no mercado de seguros.', and contact text 'contato@flexinsur.com'.
